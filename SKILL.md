# UI Styling Kit

Use this skill when the user wants better visual design, polished layout, accessible components, or a consistent design system.

## What to do
- use Tailwind and shadcn/ui patterns for layouts, forms, tables, nav, and dialogs
- keep interfaces mobile-friendly and readable
- preserve consistent spacing, typography, and color usage
- use restrained brand accents instead of overly decorative styling

## Important
- keep accessibility in mind for forms, focus states, and contrast
- match the existing brand system when one exists
- prefer clear, reusable patterns over flashy but confusing design
